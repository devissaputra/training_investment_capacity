# Contributing

Changes should preserve the source identity, comparable-wave rule, official-versus-derived distinction, and claim boundaries.

## Scientific changes

If a contribution changes the comparable years, inflation fields, reach definition, sector set, or robustness metrics, update:

- protocol;
- tests;
- derived evidence;
- scientific report;
- figures.

Do not silently change the released estimand.

## Source integrity

Preserve the dataset UUID, row count, and SHA-256 unless making a documented source-version update.

Do not add synthetic fallback data.

## Official versus derived measures

Keep the source-published expenditure measures separate from repository-derived calculations.

The trainees/employees ratio must remain clearly labelled as derived.

## Claim discipline

Do not infer training quality, learning transfer, causal ROI, or organizational capability from expenditure alone.
